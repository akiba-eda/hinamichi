# デモ動画

`hinamichi_demo.mp4`(117秒・音なし・540×1200)。先頭 3 秒はタイトルカード(`opening.html` → `opening.png`、セナヴィとロゴ)。Android エミュレータの画面録画で、
サーバーもデータも本番のもの(南行徳駅周辺)。

流れ: ふだんのホーム → 近隣情報で津波に切り替え(避難場所が入れ替わる) → 設定から地震を発火
→ 避難先の提案と30秒のカウント → **押さずに自動で案内が始まる** → 友だちに避難中が届く
→ 判断の記録で AI に渡した入力を開く(座標が無い)。

操作は adb で自動再生している。LLM の判断時間が回ごとに違うので、固定の待ち時間ではなく
Firestore の状態が「案内中」になるのを待ってから次へ進む(`scripts/lastIncident.ts` を流用)。
